# Crumble — Crunch your mood!

متجر كوكيز عربي تفاعلي، مبني كتجربة طلب واحدة بالقطعة أو بالبوكس، مع إرسال الطلبات مباشرة إلى Telegram ولوحة تحكم محلية لتعديل المحتوى وتصدير ملف JSON.

## تحديث محتوى المتجر

1. افتح `/admin`.
2. عدّل المنتجات، الصور، البوكسات، المدن أو ساعات العمل.
3. اضغط **حفظ المعاينة** لمراجعة التغييرات على نفس الجهاز.
4. اضغط **تصدير JSON** لتنزيل `store.json`.
5. استبدل الملف `data/store.json` في مستودع GitHub بالملف الجديد.
6. عند ربط المستودع بـ Vercel سيبدأ النشر الجديد تلقائياً.

> لوحة التحكم لا تعدّل المستودع أو الموقع المنشور مباشرة، لذلك لا يستطيع الزائر تغيير محتوى المتجر. النسخة المنشورة تتغير فقط بعد رفع ملف JSON إلى GitHub.

## الصور

يمكن كتابة مسار صورة موجودة داخل `public` أو رفع صورة من لوحة التحكم. الصور المرفوعة من اللوحة تُحفظ داخل JSON بصيغة Data URL، لذلك يُفضّل ضغطها وأن يكون حجمها أقل من 2.5MB. للمحتوى النهائي والأسرع، ضع الصور داخل `public/products` واستخدم مساراً مثل `/products/flavour.jpg`.

## إعداد Telegram

أضف القيم التالية في إعدادات Environment Variables على Vercel، ولا تضع القيم الحقيقية داخل GitHub:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

الواجهة ترسل الطلب إلى `/api/order`، والخادم وحده يتواصل مع Telegram. إذا لم تضف المتغيرين سيظل الموقع قابلاً للتصفح والاختيار، لكن الإرسال سيعرض رسالة تعذر مؤقتة.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## النشر على Vercel

المشروع يحتوي على `vercel.json` ويستخدم `npm run vercel-build` تلقائياً عند النشر. يكفي ربط مستودع GitHub بالمشروع في Vercel وإضافة متغيرات Telegram.
